## 1. Цели Фазы 2

1. **Закрыть критический паритет Впостера** для переезда паблик-мейкеров: маркировка ОРД (E10), отложенные истории VK/OK (E11), граббер/RSS (E17) — по спекам AN-P v1.0.1.
2. **Усилить дифференциаторы агентств:** согласование и клиентские ссылки (E8), рубрики/слоты (E9), кросс-сетевая аналитика и отчёты (E13), единый инбокс (E14), AI-студия (E15).
3. **Расширить сети и автоматизации:** Rutube (E12), кросспостинг (E16), предложка (E18), антиспам VK+TG (E19).
4. **Экосистема интеграций и миграции:** публичное API + вебхуки (E20), партнёрка (E21), импорт из Впостера (E22).
5. Сохранить NFR MVP: **0 потерь / 0 дублей**, p99 публикации ≤ 60 с, RBAC workspace, ПДн в РФ.
