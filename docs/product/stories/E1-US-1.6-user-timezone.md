## Ценность

**Как** пользователь, **я хочу** задать часовой пояс (по умолчанию из браузера), **чтобы** видеть все даты в привычном локальном времени.

## Критерии приёмки (Given / When / Then)

1. **Given** новая регистрация
   **When** браузер передаёт IANA TZ
   **Then** TZ сохранён в профиле; при отсутствии — `Europe/Moscow` как безопасный дефолт для РФ
2. **Given** пользователь меняет TZ
   **When** сохраняет настройку
   **Then** UI показывает даты в новом TZ; значения `scheduled_at` в БД остаются в UTC и **не сдвигаются** для уже запланированных постов
3. **Given** API отдаёт времена
   **When** клиент запрашивает пост/календарь
   **Then** API отдаёт UTC (ISO-8601); конвертация — на клиенте по TZ пользователя

## Тестовые данные (черновик для Тестировщика)

- Профиль с TZ `Asia/Vladivostok` и пост `scheduled_at` UTC
- Смена TZ → абсолютное время публикации неизменно
