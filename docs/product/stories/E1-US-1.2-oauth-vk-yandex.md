## Ценность

**Как** пользователь, **я хочу** войти через VK ID или Яндекс ID (OAuth 2.1 + PKCE), **чтобы** быстро начать работу без отдельного пароля.

## Критерии приёмки (Given / When / Then)

1. **Given** пользователь не авторизован
   **When** завершает OAuth VK ID / Яндекс ID с новым identity
   **Then** создаётся аккаунт (или сессия); при наличии email от провайдера - статус подтверждения по правилам провайдера; создан личный workspace
2. **Given** существует аккаунт с тем же подтверждённым email
   **When** OAuth-вход с этим email
   **Then** автоматического слияния нет; пользователю показан экран связывания; связывание только после явного подтверждения владельцем аккаунта
3. **Given** пользователь отменяет согласие / ошибка OAuth
   **When** возврат в приложение
   **Then** вход не выполнен; показана безопасная ошибка без утечки токенов
4. **Given** PKCE / state невалидны
   **When** callback OAuth
   **Then** вход отклонён; событие в аудите безопасности

## Тестовые данные (черновик для Тестировщика)

- Тестовые приложения VK ID / Яндекс ID (staging)

- Аккаунт B: новый OAuth без существующего email
