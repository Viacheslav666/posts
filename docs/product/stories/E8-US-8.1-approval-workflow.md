## Ценность

**Как** Editor/Author в агентстве, **я хочу** отправить пост на согласование и получить одобрение/отклонение с комментарием, **чтобы** клиент и команда контролировали публикации до выхода в сеть.

## Критерии приёмки (Given / When / Then)

1. **Given** пост в статусе `draft`, роль Author или Editor
   **When** отправляет «На согласование»
   **Then** статус `pending_approval`; уведомление согласующим (Owner/Admin/Editor с правом / Клиент)
2. **Given** пост `pending_approval`
   **When** согласующий одобряет
   **Then** статус `approved`; Author/Editor может запланировать; аудит `post.approved`
3. **Given** пост `pending_approval`
   **When** согласующий отклоняет с комментарием
   **Then** статус `rejected`; черновик доступен для правок; комментарий сохранён
4. **Given** Viewer без права согласования
   **When** пытается approve
   **Then** 403/deny по матрице ролей
