**Как** Admin, **я хочу** правило кросспостинга источник→приёмники с фильтрами keywords/вложений, **чтобы** зеркалировать контент без ручного копирования.

## Критерии приёмки (Given / When / Then)

1. **Given** источник VK, приёмники TG+OK
   **When** создаёт active rule
   **Then** новые посты источника создают publications в приёмниках через конвейер
2. **Given** keyword_exclude срабатывает
   **When** пост источника
   **Then** item skipped; без публикации
3. **Given** Meta IG/FB как приёмник
   **When** UI
   **Then** недоступны (вне scope)
