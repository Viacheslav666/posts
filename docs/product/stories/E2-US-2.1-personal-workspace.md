## Ценность

**Как** пользователь, **я хочу** получить личный workspace при регистрации и создавать дополнительные, **чтобы** изолировать данные клиентов/брендов и биллинг.

## Критерии приёмки (Given / When / Then)

1. **Given** завершена регистрация (US-1.1 / US-1.2)
   **When** система создаёт сущности
   **Then** создан личный workspace; пользователь - Owner; есть дефолтный проект (или онбординг предлагает создать)
2. **Given** пользователь - Owner хотя бы одного workspace
   **When** создаёт дополнительный workspace с именем
   **Then** workspace создан; пользователь Owner; биллинг и участники изолированы
3. **Given** запрос к чужому workspace_id
   **When** любой API-вызов
   **Then** ответ **404** (не 403), защита от IDOR

## Тестовые данные (черновик для Тестировщика)

- Новый пользователь → ровно 1 личный workspace
- Второй workspace; проверка изоляции данных
