## Ценность

**Как** команда SMM, **я хочу** очередь модерации по умолчанию и возможность включить auto, **чтобы** не публиковать чужой контент без просмотра.

## Критерии приёмки (Given / When / Then)

1. **Given** создание правила без явного mode
   **When** save
   **Then** `publish_mode=moderate` (обязательный режим продукта и default) (TC-GRAB-08)
2. **Given** item pending_moderation
   **When** Editor approve / reject / edit-and-approve
   **Then** approve → один post через конвейер; reject без публикации; до approve публикаций в сети нет (TC-GRAB-08/23/27)
3. **Given** пользователь явно выбирает `auto`
   **When** UI предупреждает о рисках; save
   **Then** новые items могут идти в пайплайн без очереди; moderate остаётся доступен (TC-GRAB-08b/09)
4. **Given** Author без moderate
   **When** approve
   **Then** 403; Viewer - только view по матрице (TC-GRAB-15)
