## Ценность

**Как** участник команды, **я хочу** комментировать пост с @упоминаниями и видеть версии правок, **чтобы** согласовывать контент асинхронно.

## Критерии приёмки (Given / When / Then)

1. **Given** участник с правом комментировать
   **When** оставляет комментарий с @mention
   **Then** уведомление упомянутому; комментарий в ленте поста
2. **Given** после правок текста
   **When** открывает историю версий
   **Then** видны diff ключевых полей; можно откатить черновик к версии (Editor+)

## Тестовые данные (черновик для Тестировщика)

- 3 версии черновика; 2 комментария
