## Ценность

**Как** Owner или Admin, **я хочу** создавать проекты (клиенты/бренды) и привязывать к ним каналы, **чтобы** структурировать работу команды по клиентам.

## Критерии приёмки (Given / When / Then)

1. **Given** роль Owner/Admin
   **When** создаёт проект с названием
   **Then** проект создан в workspace; доступен в списках Owner/Admin
2. **Given** канал подключается
   **When** указывается проект
   **Then** канал принадлежит проекту; участник без ProjectGrant проект/канал не видит (404)
3. **Given** Editor с grant только на проект A
   **When** открывает проект B
   **Then** 404

## Тестовые данные (черновик для Тестировщика)

- Workspace с проектами A/B; участник Editor только на A
- Канал в A виден, в B - 404
