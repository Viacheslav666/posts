## Ценность

**Как** роль с `posts.bulk`, **я хочу** паузировать/возобновлять/удалять/переносить выбранные посты, **чтобы** управлять очередью контента целиком.

## Критерии приёмки (Given / When / Then)

1. **Given** выбраны scheduled-посты
   **When** пауза
   **Then** статус `paused`; публикации не уходят в конвейер
2. **Given** paused
   **When** возобновление
   **Then** возврат в `scheduled` если время в будущем; иначе - по правилам scheduler
3. **Given** выбранные посты
   **When** удаление (с подтверждением)
   **Then** посты удалены из сервиса; опубликованные в сети - по отдельному правилу (не удалять из сети без явного флага)
4. **Given** перенос
   **When** новая дата
   **Then** всем выбранным обновлён `scheduled_at`

## Тестовые данные (черновик для Тестировщика)

- 10 scheduled постов; bulk pause/resume/move
