## Ценность

**Как** Owner/Admin и команда, **я хочу** видеть статус канала и получать уведомление при проблеме с токеном, **чтобы** не потерять запланированные посты при отвязке соцсети.

## Критерии приёмки (Given / When / Then)

1. **Given** токен отозван или истёк
   **When** детектор/API сети сообщает об ошибке авторизации
   **Then** статус канала → `reconnect_required` (или `insufficient_permissions`); Owner и Admin уведомлены **≤ 5 мин**
2. **Given** у канала есть запланированные публикации
   **When** токен отозван
   **Then** посты **не удаляются**; публикации получают `waiting_for_channel`
3. **Given** пользователь переподключает канал
   **When** токен снова валиден
   **Then** статус `active`; ожидающие публикации возобновляют конвейер по правилам scheduler
4. **Given** канал отключён вручную
   **When** Owner/Admin отключает
   **Then** статус `disabled`; новые публикации в него недоступны

## Тестовые данные (черновик для Тестировщика)

- Симуляция revoke токена в эмуляторе
- Пост scheduled на канал → waiting_for_channel
- Метрика времени до уведомления
