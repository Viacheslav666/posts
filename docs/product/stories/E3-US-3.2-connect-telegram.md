## Ценность

**Как** Owner или Admin, **я хочу** подключить канал/группу Telegram через @PostsBot, **чтобы** публиковать в Telegram из Posts.

## Критерии приёмки (Given / When / Then)

1. **Given** бот добавлен админом с нужными правами
   **When** пользователь указывает @username или пересылает пост
   **Then** канал появляется со статусом `active`
2. **Given** проверка прав бота
   **When** система валидирует подключение
   **Then** требуются `can_post_messages`, `can_edit_messages`, `can_delete_messages`, `can_pin_messages`; при отсутствии — `insufficient_permissions` и инструкция
3. **Given** бот не в чате / неверный username
   **When** попытка подключить
   **Then** понятная ошибка без создания «битого» канала

## Тестовые данные (черновик для Тестировщика)

- Тестовый TG-канал; бот с полными и урезанными правами
- Эмулятор Telegram Bot API
