## Ценность

**Как** Owner/Admin/Editor (в scope проектов), **я хочу** создавать наборы до 50 каналов для публикации в один клик, **чтобы** быстрее планировать кросс-постинг.

## Критерии приёмки (Given / When / Then)

1. **Given** есть каналы в доступных проектах
   **When** создаётся набор ≤ 50 каналов
   **Then** набор сохранён; доступен в редакторе поста
2. **Given** попытка добавить 51-й канал
   **When** сохранение
   **Then** валидация отклоняет; сообщение о лимите 50
3. **Given** ★ лимит
   **When** сравнение с Впостером
   **Then** лимит Posts = 50 (у Впостера 20)

## Тестовые данные (черновик для Тестировщика)

- Набор из 50 каналов — OK; 51 — ошибка
