## Ценность

**Как** участник workspace, **я хочу** получать уведомления о ошибках публикации, канале, биллинге, приглашениях, **чтобы** мгновенно реагировать на сбои.

## Критерии приёмки (Given / When / Then)

1. **Given** ошибка публикации / канал reconnect / низкий баланс|окончание тарифа / приглашение / запрос согласования
   **When** событие возникает
   **Then** уведомление доставлено в включённые каналы: email, Telegram-бот, in-app, push PWA
2. **Given** пользователь отключает тип в настройках
   **When** событие
   **Then** этот канал/тип не отправляется
3. **Given** критичная ошибка публикации
   **When** событие
   **Then** доставка стремится к «мгновенной» (цель UX; SLO уточняется Devops); запись в in-app гарантирована

## Тестовые данные (черновик для Тестировщика)

- Mailpit; тестовый TG chat id
- Матрица типов × каналов доставки
