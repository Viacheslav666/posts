## Ценность

**Как** разработчик/интегратор, **я хочу** выпустить API-ключ с scopes, **чтобы** управлять постами/каналами вне UI (паритет+ превосходство над API v3 Впостера).

## Критерии приёмки (Given / When / Then)

1. **Given** Owner
   **When** создаёт ключ с scopes posts:read/write
   **Then** ключ показан один раз; hash в БД; rate limit
2. **Given** ключ без scope
   **When** вызывает write
   **Then** 403
3. **Given** revoke
   **When** повторный вызов
   **Then** 401
