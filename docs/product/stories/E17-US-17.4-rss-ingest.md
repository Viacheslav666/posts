## Ценность

**Как** Editor, **я хочу** подключить RSS/Atom фид к каналу с теми же режимами moderate/auto, **чтобы** импортировать новости без отдельного «острова» как у Впостера.

## Критерии приёмки (Given / When / Then)

1. **Given** type=rss, валидный feed URL
   **When** activate + run
   **Then** items из RSS 1.0/2.0/Atom → тот же путь модерации/пайплайна (TC-GRAB-11)
2. **Given** rss_url указывает на private IP / metadata
   **When** preview/activate/run
   **Then** SSRF block `ingest_ssrf_blocked` (TC-GRAB-12)
3. **Given** чужой workspace rule id
   **When** GET/PATCH
   **Then** 404 IDOR (TC-GRAB-16)
