## Ценность

**Как** Editor, **я хочу** загрузить N медиа → N историй с шагом времени, **чтобы** быстро наполнить расписание.

## Критерии приёмки (Given / When / Then)

1. **Given** 10 файлов, один канал, шаг +5 мин
   **When** batch create
   **Then** 10 сущностей `content_kind=story` в календаре (TC-STORY-10)
2. **Given** >50 файлов
   **When** batch
   **Then** отказ/обрезка по `posts.stories.batch_max=50` (TC-STORY-25)

## Тестовые данные (черновик для Тестировщика)

- 10 JPEG; лимит 50
