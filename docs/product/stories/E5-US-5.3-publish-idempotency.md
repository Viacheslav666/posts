## Ценность

**Как** система, **я хочу** при повторной доставке задачи из очереди не создавать второй пост в сети, **чтобы** гарантировать 0 дублей при at-least-once.

## Критерии приёмки (Given / When / Then)

1. **Given** задача публикации доставлена повторно (redelivery)
   **When** publisher обрабатывает дважды
   **Then** в сети создан **максимум 1** пост (guid / findExisting / идемпотентный ключ)
2. **Given** убийство publisher mid-flight + redelivery
   **When** хаос-сценарий
   **Then** 0 дублей, 0 потерь
3. **Given** успех без ответа сети + повтор
   **When** обработка
   **Then** второй вызов не создаёт дубль
