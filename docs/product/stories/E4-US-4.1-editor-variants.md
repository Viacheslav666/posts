## Ценность

**Как** Editor/Author (создание), Owner/Admin/Editor (публикация), **я хочу** редактировать общий текст и варианты под каждую сеть с предпросмотром, **чтобы** получить корректный вид поста в каждой сети до публикации.

## Критерии приёмки (Given / When / Then)

1. **Given** открыт новый пост
   **When** пользователь вводит общий текст и выбирает каналы разных сетей
   **Then** для сетей без переопределения используется общий контент; можно создать PostVariant
2. **Given** вариант подсеть превышает лимит символов сети
   **When** попытка сохранить/запланировать
   **Then** сохранение заблокировано; подсвечена причина и счётчик
3. **Given** предпросмотр
   **When** переключение вкладок сетей
   **Then** отображается предпросмотр согласно NetworkCapabilities (AN-2)
4. **Given** Author
   **When** создаёт черновик
   **Then** успех; `posts.schedule` недоступен (roles)

## Тестовые данные (черновик для Тестировщика)

- Текст длиннее лимита VK/TG
- Вариант только для TG
- Роли Author vs Editor
