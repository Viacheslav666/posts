## Ценность

**Как** Owner или Admin, **я хочу** видеть кто / что / когда / IP сделал в workspace, **чтобы** разбирать инциденты и контролировать команду.

## Критерии приёмки (Given / When / Then)

1. **Given** участник выполнил значимое действие (приглашение, смена роли, подключение канала, планирование, биллинг)
   **When** Owner/Admin открывает аудит
   **Then** запись содержит actor, action, object, timestamp UTC, IP; хранение ≥ 1 год (политика ретенции)
2. **Given** Editor/Author/Viewer
   **When** запрашивает audit.view
   **Then** 403 на своём workspace / 404 на чужом
3. **Given** Owner/Admin
   **When** экспортирует CSV
   **Then** P1: файл выгружается; до реализации P1 - пункт в UI скрыт/disabled

## Тестовые данные (черновик для Тестировщика)

- Набор действий от разных ролей
- Проверка прав deny для Editor
- P1-метка на экспорт
