## Ценность

**Как** маркетолог/агентство, **я хочу** единый дашборд охватов/ER по VK/TG/OK/Max/Rutube, **чтобы** сравнивать эффективность без выгрузок из каждой сети.

## Критерии приёмки (Given / When / Then)

1. **Given** есть публикации ≥7 дней
   **When** открывает Аналитика
   **Then** метрики по сетям/проектам; пустые сети - empty state
2. **Given** Viewer клиента
   **When** смотрит только свои проекты
   **Then** IDOR 404 на чужие
