## Ценность

**Как** Owner продукта/пользователь, **я хочу** обязательную атрибуцию, чекбокс ответственности и дедуп, **чтобы** снизить юр. риск и исключить двойные публикации.

## Критерии приёмки (Given / When / Then)

1. **Given** activate без attribution или без responsibility
   **When** activate
   **Then** 422 `ingest_attribution_required` / `ingest_responsibility_required` (TC-GRAB-07)
2. **Given** повторный ingest того же remote_post_id / того же content_hash
   **When** run
   **Then** вторая публикация не создаётся; items_deduped (TC-GRAB-05/06)
3. **Given** опубликованный item
   **When** смотрит текст
   **Then** футер атрибуции по шаблону; source_permalink в истории
4. **Given** redelivery run
   **When** ingest
   **Then** 0 дублей публикаций в сети (TC-GRAB-13/14)
