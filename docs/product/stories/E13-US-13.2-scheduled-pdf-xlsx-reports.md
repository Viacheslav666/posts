## Ценность

**Как** агентство, **я хочу** слать брендированный отчёт клиенту на email по расписанию, **чтобы** закрывать отчётность без ручной сборки.

## Критерии приёмки (Given / When / Then)

1. **Given** проект с логотипом
   **When** настраивает отчёт weekly PDF
   **Then** письмо с вложением; данные только проекта
2. **Given** XLSX экспорт
   **When** скачивает
   **Then** листы по сетям/постам

## Тестовые данные (черновик для Тестировщика)

- SMTP/Mailpit; 1 scheduled report
