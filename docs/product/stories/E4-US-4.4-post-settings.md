## Ценность

**Как** роль с `posts.schedule` (для планирования) / создание черновика - Author+, **я хочу** задать дату/время или «сейчас», повторы, закреп/откреп, автоудаление, mute, комментарии, подпись, первый комментарий, кнопки, карусель, **чтобы** покрыть паритет параметров постинга с Впостером.

## Критерии приёмки (Given / When / Then)

1. **Given** валидные дата/время в будущем (TZ пользователя)
   **When** сохранение как scheduled
   **Then** пост `scheduled`; `scheduled_at` в UTC
2. **Given** «опубликовать сейчас»
   **When** Editor+
   **Then** конвейер запускается немедленно
3. **Given** повтор everyday / weekdays / weekends / every N days|weeks|months до даты
   **When** сохранение
   **Then** создано правило Recurrence; ближайшие экземпляры материализуются
4. **Given** закреп + дата открепления; автоудаление N часов/дата; mute; close comments VK/OK; signed VK; first comment; кнопки TG/Max; карусель/сетка VK
   **When** сохранение для поддерживающей сети
   **Then** настройки сохранены; для неподдерживающей сети - скрыты/disabled по capabilities
5. **Given** Author
   **When** пытается schedule
   **Then** 403/deny по матрице
