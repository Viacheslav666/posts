## Ценность

**Как** Owner или Admin, **я хочу** подключить личную страницу VK и группы, где я админ/редактор, **чтобы** планировать публикации во ВКонтакте.

## Критерии приёмки (Given / When / Then)

1. **Given** email подтверждён; есть проект; не превышен лимит каналов
   **When** пользователь проходит OAuth VK и выбирает группы/страницу из списка с аватарами
   **Then** каналы созданы со статусом `active`; токены зашифрованы (envelope/KMS)
2. **Given** у пользователя нет прав админа/редактора на группу
   **When** попытка подключить
   **Then** понятная ошибка с инструкцией, как получить права
3. **Given** токен группы для Callback (Фаза 2)
   **When** подключение MVP
   **Then** в MVP достаточно токена для публикации; задел под Callback документирован, полный Callback — Фаза 2

## Тестовые данные (черновик для Тестировщика)

- Тестовая VK-группа (админ) и группа без прав
- Эмулятор VK / staging OAuth
