## Ценность

**Как** партнёр, **я хочу** реферальную ссылку и начисления % с оплат, **чтобы** монетизировать привлечение (паритет 20 % Впостера, ★ вывод для юрлиц - цель).

## Критерии приёмки (Given / When / Then)

1. **Given** партнёр
   **When** получает referral link
   **Then** оплаты рефералов → бонус на баланс/ledger
2. **Given** юрлицо/самозанятый (P2)
   **When** запрашивает вывод
   **Then** заявка + KYC/реквизиты; до реализации вывода - только баланс как у Впостера

## Тестовые данные (черновик для Тестировщика)
