## Ценность

**Как** мигрант с Впостера, **я хочу** импортировать группы/посты/истории по своему API-ключу v3, **чтобы** переехать в Posts в один клик ★.

## Критерии приёмки (Given / When / Then)

1. **Given** пользователь вводит Bearer API v3
   **When** запускает import
   **Then** каналы сопоставлены/созданы; scheduled posts/stories → draft/scheduled; пароль/токены vposter не хранятся дольше импорта
2. **Given** частичный сбой страницы API
   **When** job
   **Then** idempotent resume; отчёт ошибок по сущностям
3. **Given** IG-сущности из vposter
   **When** import
   **Then** пропуск с записью в отчёте (IG вне scope Posts)
