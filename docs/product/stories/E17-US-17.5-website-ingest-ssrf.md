## Ценность

**Как** Editor, **я хочу** импортировать статьи с сайтов (OG/extract) с жёсткой защитой от SSRF, **чтобы** расширить источники beyond VK/RSS.

## Критерии приёмки (Given / When / Then)

1. **Given** type=website, публичный URL статьи
   **When** run
   **Then** item с title/text/image; дальше moderate/auto как у граббера (TC-GRAB-21)
2. **Given** URL localhost / link-local / rebinding
   **When** preview/run
   **Then** блок SSRF; без исходящего запроса во внутреннюю сеть
