## Ценность

**Как** пользователь, забывший пароль, **я хочу** сбросить пароль по email, **чтобы** восстановить доступ к аккаунту.

## Критерии приёмки (Given / When / Then)

1. **Given** аккаунт с подтверждённым email существует
   **When** запрос восстановления
   **Then** отправляется письмо со ссылкой TTL 1 ч, одноразовой; UI всегда показывает нейтральный успех (анти-энумерация)
2. **Given** валидная одноразовая ссылка < 1 ч
   **When** пользователь задаёт новый пароль (правила US-1.1)
   **Then** пароль изменён; **все** активные сессии завершены; требуется новый вход
3. **Given** ссылка истекла, уже использована или подделана
   **When** попытка сброса
   **Then** смена пароля не выполняется; предложено запросить новую ссылку
4. **Given** 2FA включена
   **When** после сброса пароля пользователь входит
   **Then** по-прежнему требуется второй фактор (US-1.3)

## Тестовые данные (черновик для Тестировщика)

- Пользователь с 1+ активными сессиями (web + «другое устройство»)
- Токен reset: валидный / expired / reused
