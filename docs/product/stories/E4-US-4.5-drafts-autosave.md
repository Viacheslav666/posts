## Критерии приёмки (Given / When / Then)

1. **Given** открыт черновик
   **When** пользователь печатает
   **Then** автосохранение не реже чем раз в **5 с** после изменения (debounce)
2. **Given** есть несохранённые изменения (сбой сети)
   **When** закрытие вкладки
   **Then** браузер показывает предупреждение beforeunload
3. **Given** повторное открытие
   **When** пользователь возвращается
   **Then** восстановлена последняя сохранённая версия

## Тестовые данные (черновик для Тестировщика)

- Мок задержки сети; проверка интервала autosave
- beforeunload при dirty state
