## Ценность

**Как** Editor, **я хочу** вести справочник рекламодателей и договоров и выбирать ККТУ/страну из справочников, **чтобы** быстро заполнять маркировку без ошибок ИНН/ККТУ.

## Критерии приёмки (Given / When / Then)

1. **Given** ORD connection active
   **When** создаёт contractor (ИНН, КПП, тип, ОКСМ)
   **Then** запись в `ord_contractors`; уникальность (workspace, inn, kpp); автоподстановка имени по ИНН ★ при наличии сервиса
2. **Given** contractor есть
   **When** создаёт contract (даты, сумма, НДС, serial)
   **Then** договор связан с provider_ref после sync; self-promo - упрощённый поток
3. **Given** любой Editor+
   **When** открывает справочники ККТУ/ОКСМ
   **Then** данные из кэша `GET /ord/dictionaries/*`; поиск по коду/названию
4. **Given** невалидный ИНН (не 10/12 цифр)
   **When** сохраняет contractor/ad
   **Then** 422 `ad_inn_invalid`
