## Ценность

**Как** владелец аккаунта, **я хочу** включить 2FA TOTP и получить 10 резервных кодов, **чтобы** защитить аккаунт от компрометации пароля/OAuth.

## Критерии приёмки (Given / When / Then)

1. **Given** пользователь вошёл без 2FA
   **When** включает 2FA, сканирует секрет и подтверждает код TOTP
   **Then** 2FA активна; выдано ровно 10 одноразовых резервных кодов (показываются один раз); без валидного кода следующий вход невозможен
2. **Given** 2FA включена
   **When** вход с верным паролем/OAuth, но без TOTP/резервного кода
   **Then** сессия не создаётся; запрошен второй фактор
3. **Given** 2FA включена
   **When** вход с верным резервным кодом
   **Then** вход успешен; использованный код инвалидирован
4. **Given** 2FA включена
   **When** пользователь пытается сбросить 2FA самообслуживанием без поддержки
   **Then** самостоятельный сброс недоступен; инструкция обратиться в поддержку с верификацией личности
5. **Given** поддержка после верификации
   **When** сбрасывает 2FA
   **Then** 2FA отключена; событие в аудит-логе; пользователю рекомендовано включить заново

## Тестовые данные (черновик для Тестировщика)

- TOTP secret (test vector), коды для текущего окна ±1
- 10 резервных кодов; повторное использование одного кода → отказ
- Роль platform_admin для сценария сброса
