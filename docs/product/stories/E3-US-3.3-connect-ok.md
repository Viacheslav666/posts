## Ценность

**Как** Owner или Admin, **я хочу** подключить группы Одноклассников через OAuth, **чтобы** публиковать в OK.

## Критерии приёмки (Given / When / Then)

1. **Given** OAuth OK успешен
   **When** пользователь выбирает доступные группы
   **Then** каналы `active`; токены зашифрованы
2. **Given** нет прав на группу
   **When** выбор группы
   **Then** ошибка с инструкцией
