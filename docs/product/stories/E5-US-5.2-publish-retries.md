## Ценность

**Как** система публикаций, **я хочу** ретраить временные сбои и явно падать на постоянных, **чтобы** не терять посты и не оставлять пользователя без причины.

## Критерии приёмки (Given / When / Then)

1. **Given** сеть отвечает 5xx / 429 / flood control
   **When** публикация
   **Then** автоповторы с экспоненциальной задержкой; суммарное окно ретраев до **30 мин**; PublicationAttempt пишется
2. **Given** постоянная ошибка (нет прав, невалидный токен)
   **When** публикация
   **Then** статус `failed` / канал может → reconnect; человекочитаемая причина; кнопка «Повторить» для Editor+
3. **Given** после исчерпания ретраев
   **When** задача
   **Then** DLQ / failed; пост не удалён

## Тестовые данные (черновик для Тестировщика)

- Эмулятор: 429 + retry_after; 5xx; error 15 VK
- TC-PUB ретраи
