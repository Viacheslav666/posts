## Ценность

**Как** пользователь, **я хочу** видеть только поддерживаемые сети для историй, **чтобы** не планировать заведомо невозможные публикации.

## Критерии приёмки (Given / When / Then)

1. **Given** UI селектор сетей истории
   **When** открывает create story
   **Then** доступны только VK и OK; TG/Max скрыты с пояснением; **Instagram отсутствует** (Q-STORY-05) (TC-STORY-13/28)
2. **Given** API `contentKind=story` для telegram|max|ig
   **When** create/schedule
   **Then** 422 `story_unsupported_network`
