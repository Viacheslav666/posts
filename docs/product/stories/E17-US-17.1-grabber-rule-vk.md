## Ценность

**Как** Editor, **я хочу** создать правило граббера с источниками и целевым VK-каналом, запускать скан и видеть историю, **чтобы** копировать контент с паритетом Впостера.

## Критерии приёмки (Given / When / Then)

1. **Given** VK-канал ok, Editor
   **When** создаёт rule type=grabber с source_ids, attribution, responsibility
   **Then** 201; если publish_mode не передан — **moderate**; видно в активных (TC-GRAB-01/22)
2. **Given** правило active
   **When** наступает interval / «Проверить сейчас»
   **Then** grabber_runs; новые items; ручной run rate-limit (TC-GRAB-02/03)
3. **Given** есть items
   **When** открывает историю
   **Then** permalink, превью, статус, postId после publish (TC-GRAB-04)
4. **Given** пауза/resume
   **When** переключает
   **Then** новые runs не стартуют на pause (TC-GRAB-10)

## Тестовые данные (черновик для Тестировщика)

- Источник-эмулятор с 2 постами; interval 15 мин в тесте
