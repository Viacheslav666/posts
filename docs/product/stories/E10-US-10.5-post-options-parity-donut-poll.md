## Ценность

**Как** паблик-мейкер с Впостера, **я хочу** все опции `posts.create` API v3 в редакторе Posts, **чтобы** перенести сценарии без потери настроек.

## Критерии приёмки (Given / When / Then)

1. **Given** канал VK
   **When** задаёт `donutDays` 0–7, `coOwnerIds` ≤4, poll, `stopAt`, `removeFromServiceAfterPublish`
   **Then** опции сохранены в variants; неподдерживаемые сети — disabled по capabilities
2. **Given** action_button / geo / copyright / linkSnippet
   **When** сохраняет пост
   **Then** поля в content/options; публикация через конвейер без регресса TC-PUB

## Тестовые данные (черновик для Тестировщика)

- VK канал; 2 соавтора; опрос 3 ответа
