## Ценность

**Как** роль с posts.schedule, **я хочу** запланировать репост существующего объекта сети с комментарием, **чтобы** не копировать контент вручную.

## Критерии приёмки (Given / When / Then)

1. **Given** указан валидный объект репоста VK/TG/OK
   **When** планирование с комментарием
   **Then** публикация выполняет репост; комментарий прикреплён по правилам сети
2. **Given** объект недоступен / нет прав
   **When** публикация
   **Then** failed с человекочитаемой причиной
3. **Given** сеть Max
   **When** UI репоста
   **Then** не предлагается (вне scope MVP для Max)

## Тестовые данные (черновик для Тестировщика)

- Валидный wall object VK; невалидный id
