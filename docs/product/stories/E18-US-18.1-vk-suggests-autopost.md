## Ценность

**Как** админ паблика, **я хочу** автоматически публиковать предложку по фильтрам Впостера (+ массовые действия), **чтобы** не модерировать вручную каждую запись.

## Критерии приёмки (Given / When / Then)

1. **Given** Callback API сообщества настроен
   **When** создаёт правило suggest с keyword/author/limits
   **Then** подходящие proposed posts → publications; непрошедшие — по политике delete/skip
2. **Given** ручная модерация + «опубликовать всё»
   **When** массовое действие
   **Then** только выбранные/все pending опубликованы через конвейер
