## 6. Как отвечать

1. Прикрепить PNG/PDF скриншотов с подписью ID вопроса (`Q-GRAB-01`).
2. Для каждого ID: «подтверждаю допущение» / «нет, правильно так: …».
3. После ответов Аналитик обновляет features-спеки (patch-версия) и снимает соответствующие ASSUMPTION-маркеры.

По открытым ID **BE/FE реализуют допущения** из этого файла и соответствующих спецификаций. Закрытые ID (§0) — только как **решение**, без ASSUMPTION.
