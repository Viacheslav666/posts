# Глоссарий Posts

| Поле | Значение |
|---|---|
| Версия | 1.0 |
| Статус | На утверждении (гейт A, AN-1) |
| Дата | 2026-11-17 |
| Назначение | Единый язык для PRD, stories, OpenAPI, кода и тестов |

Правила именования: в документах — русские термины; в коде/API/YAML — английские идентификаторы из колонки **ID**. Синонимы Впостера указаны для миграции и поддержки.

---

## A. Организация и доступ

| Термин | ID | Определение |
|---|---|---|
| **Аккаунт (пользователь)** | `Account` / `User` | Учётная запись человека: email и/или OAuth (VK ID, Яндекс ID), 2FA, TZ, сессии. Один аккаунт может состоять в нескольких workspace. |
| **Workspace (рабочее пространство)** | `Workspace` | Граница биллинга, участников и данных. При регистрации создаётся личный workspace; можно создать дополнительные. Удаление — только Owner. **★** нет у Впостера. |
| **Проект** | `Project` | Сущность внутри workspace (клиент, бренд, направление). Каналы и посты привязываются к проекту. Доступ участника ограничивается назначенными проектами. **★** |
| **Участник** | `Member` | Аккаунт в составе workspace с ролью и набором проектов. |
| **Роль** | `Role` | Owner, Admin, Editor, Author, Viewer — см. `roles-permissions.md`. |
| **Приглашение** | `Invitation` | Запрос вступить в workspace по email: роль + проекты; TTL **7 дней**; расход места по тарифу. **★** |
| **Назначение на проект** | `ProjectGrant` | Связь Member ↔ Project. Без grant участник (кроме Owner/Admin) проект не видит. |
| **Аудит-лог** | `AuditLog` | Запись «кто / что / когда / IP / объект»; хранение **1 год**; экспорт CSV — P1. **★** |
| **Сессия** | `Session` | Активный вход (JWT/refresh); пользователь может завершать чужие сессии из истории входов. |
| **Часовой пояс пользователя** | `UserTimezone` | IANA TZ; UI показывает локальное время; в БД время хранится в **UTC**. Смена TZ не сдвигает абсолютное `scheduled_at` уже запланированных постов. |

## B. Каналы и сети

| Термин | ID | Определение |
|---|---|---|
| **Сеть (соцсеть)** | `Network` | Площадка публикации. MVP: `vk`, `telegram`, `ok`, `max`. Фаза 2+: `rutube` и др. |
| **Канал** | `Channel` | Подключённая к проекту сущность сети: VK-группа или личная страница, TG-канал/группа, группа OK, чат/канал Max. Хранит зашифрованные токены и статус. |
| **Статус канала** | `ChannelStatus` | `active` \| `reconnect_required` \| `insufficient_permissions` \| `disabled`. При отзыве/истечении токена — уведомление Owner/Admin ≤ 5 мин; запланированные посты **не удаляются**, получают ожидание канала. **★** |
| **Набор каналов** | `ChannelSet` | Именованная группа каналов для публикации в один клик; до **50** каналов (у Впостера — 20). **★** лимит |
| **Адаптер сети** | `SocialAdapter` | Серверный модуль публикации/операций для конкретной сети (`social-vk`, …). |
| **Возможности сети** | `NetworkCapabilities` | Машиночитаемые лимиты и фичи сети (текст, медиа, форматирование, закреп…). Артефакт AN-2. |

*Синоним Впостера:* «сообщество» / «страница» / «группа» ≈ **Канал**; «набор страниц» ≈ **Набор каналов**.

## C. Контент и планирование

| Термин | ID | Определение |
|---|---|---|
| **Пост** | `Post` | Единица контента в Posts: общий черновик + варианты под сети + целевые каналы + расписание/настройки. Не путать с публикацией в конкретной сети. |
| **Вариант (под сеть)** | `PostVariant` | Переопределение текста, медиа и/или настроек поста для одной сети. Если не задан — используется общий контент. **★** нет у Впостера как first-class. |
| **Черновик** | `Draft` | Пост в статусе `draft`; автосохранение каждые **5 с**. |
| **Медиа-актив** | `MediaAsset` | Файл в медиатеке (S3): фото/видео/документ; метаданные, sha256, превью. |
| **Медиатека** | `MediaLibrary` | Хранилище медиа workspace/проекта. В MVP — базовая; полный DAM — Фаза 2+. **★** vs отсутствие у Впостера |
| **Расписание / scheduled_at** | `scheduled_at` | Момент публикации (UTC). UI — в TZ пользователя. |
| **Повтор (рекуррентность)** | `Recurrence` | Правило повтора: once, daily, weekdays, weekends, every N days/weeks/months до даты. Материализация ближайших экземпляров. **≈** |
| **Закреп / откреп** | `Pin` / `Unpin` | Закрепить пост в сети и опционально открепить в дату. |
| **Автоудаление** | `AutoDelete` | Удалить пост из сети через N часов или в дату. |
| **Первый комментарий** | `FirstComment` | Комментарий, публикуемый сразу после поста (где поддерживает сеть). |
| **Репост** | `Repost` | Публикация существующего объекта сети с опциональным комментарием (VK/TG/OK). |
| **Контент-календарь** | `ContentCalendar` | Представление постов: месяц / неделя / список; drag&drop меняет время (опубликованные — нельзя). **★** |
| **Массовая операция** | `BulkAction` | Пауза / возобновление / удаление / перенос выбранных постов. |
| **Рубрика** | `Rubric` | Цветовая/тематическая метка контент-плана (**Фаза 2**, E9). В глоссарии заранее для единообразия. |
| **Слот** | `Slot` | Ячейка расписания контент-плана, напр. «вт 10:00 — Кейсы» (**Фаза 2**, E9). |
| **Очередь автозаполнения** | `SlotQueue` | Очередь черновиков, заполняющая ближайшие свободные слоты (**Фаза 2**). |

## D. Публикация и статусы

| Термин | ID | Определение |
|---|---|---|
| **Публикация** | `Publication` | Факт (попытка) вывода поста в **конкретный канал**: статус, remote id, ссылка, ошибки. У одного поста — N публикаций по каналам. |
| **Статус поста (агрегат)** | `PostStatus` | `draft` → (`pending_approval` → `approved` / `rejected` — Фаза 2) → `scheduled` → `publishing` → `published` / `partially_published` / `failed` / `paused` / `deleted_from_network`. |
| **Статус публикации (канал)** | `PublicationStatus` | Статус по одному каналу; включает `waiting_for_channel` при проблеме с токеном. |
| **Попытка публикации** | `PublicationAttempt` | Запись ретрая (код ошибки, задержка, результат). |
| **Идемпотентность публикации** | `PublishIdempotency` | Гарантия: повторная доставка задачи создаёт в сети **не более одного** поста (guid / findExisting). **★** |
| **Outbox** | `Outbox` | Транзакционная таблица событий доставки в RabbitMQ. |
| **DLQ** | `DeadLetterQueue` | Очередь неисправимых/исчерпавших ретраи задач; ретрай из админки. |
| **Ожидает канал** | `waiting_for_channel` | Публикация отложена из‑за статуса канала; пост не удалён. **★** |

## E. Согласование и клиенты (задел / Фаза 2)

| Термин | ID | Определение |
|---|---|---|
| **Согласование** | `Approval` | Процесс черновик → на согласовании → одобрен/отклонён. Полноценный UX и клиентские ссылки — **Фаза 2 (E8)**; права Viewer заложены в матрице MVP. **★** |
| **Клиентская ссылка** | `ApprovalLink` | Публичная ссылка на пост для клиента без полного аккаунта (**Фаза 2**). |
| **Комментарий к посту** | `PostComment` | Внутренний комментарий команды/клиента к черновику (не комментарий в соцсети). |

## F. Биллинг и лимиты

| Термин | ID | Определение |
|---|---|---|
| **Тариф (план)** | `Plan` | Free, Start, Pro, Agency, Enterprise — лимиты каналов, мест, постов, AI-кредитов. **★** сегментация |
| **Место в команде** | `Seat` | Слот участника в workspace по тарифу. |
| **Триал** | `Trial` | 7 дней тарифа Про без карты. |
| **Grace-период** | `GracePeriod` | 3 дня после неоплаты: публикации работают, баннер. |
| **Заморозка** | `Freeze` | После grace: новые публикации на паузе, данные хранятся 90 дней, посты не удаляются. |
| **Промокод** | `PromoCode` | Скидка %, фикс, дни триала; лимит активаций и срок. |
| **AI-кредит** | `AiCredit` | Единица квоты AI; списание — Фаза 2, учёт в тарифе — MVP. |
| **Посуточный баланс** | `DailyBalance` | Режим списания как у Впостера (**P1**, для мигрантов). **≈** опционально |
