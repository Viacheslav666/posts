# Анализ сервиса Впостер (vposter.ru) и план превосходства

Дата анализа: 17.11.2026. Источники: публичные страницы vposter.ru (лендинг, /page/*, /cover, /adsmarket, /app, /legal/*), sitemap.xml, robots.txt, база знаний help.vposter.ru (88 страниц, включая Swagger API v3), 355 статей блога, отзывы (otzyvmarketing.ru, sites.reviews, headofseo.ru, tbank.ru), обзоры конкурентов. Регистрации и входа не было — функционал личного кабинета восстановлен по документации, API и блогу. Сырые тексты: `/workspace/vposter/raw/`.

## 1. Что такое Впостер в двух словах

Российский SMM-«комбайн», исторически заточенный под **ВКонтакте**. Ядро — отложенный постинг в 7 сетей (VK, OK, Telegram, Max, Rutube, Instagram*, Facebook*) + десятки VK-утилит (автопостинг предложки, антиспам, граббер, RSS, боты, конкурсы, динамические обложки, автоворонки, мессенджер диалогов) + автоматическая маркировка рекламы через ОРД (VK ОРД, ОРД Яндекса) + биржа рекламы AdsMarket + публичные страницы «анонимных сообщений/комментариев» для групп.

- Публичные цифры на лендинге: **113K подключённых сообществ, 101K пользователей**.
- Владелец: ИП Гайнитдинов Р.Ф.; ПО в реестре российского ПО; хостинг — ООО «Бегет» (один провайдер).
- Вход только через **VK ID** (далее можно задать логин/пароль и 2FA Google Authenticator).
- Техника (по HTML): серверный рендер, jQuery, PHP-эндпоинты (`sitemap/*.php`), PWA (manifest, push), виджет поддержки — VK Community Messages, аналитика — Яндекс.Метрика/GTM/Mail.ru.
- Поддержка: будни 9:00–19:00 МСК, в выходные не работает; чат взаимопомощи в VK.

\* Meta (Facebook, Instagram) признана экстремистской организацией в РФ; реклама в этих сетях в РФ запрещена.

### 2.2. Отложенный постинг (ядро)
- **Сети:** VK (посты, репосты, истории, клипы), OK (посты, репосты, моменты), Telegram (посты, кнопки), Max (посты), Rutube (видео и Shorts), Instagram* Business (посты, истории), Facebook* (посты). В API: `type_social ∈ {vk, tg, ok, ig_business, max, rutube, fb}`.
- **Редактор поста:** текст, вложения (фото, видео, аудио, документы, опросы, плейлисты — в VK-формате и новом `attachments_json`), выбор групп, календарь даты, блоки настроек. Форматирование HTML только для TG (`b,i,strike,u,span,a,blockquote,blockquote_expandable,code,pre`) и Max (`b,i,code,blockquote,a,h1,strike,u`).
- **Параметры поста (из API v3):** `date_post`, **повторы `post_day`** (oneraz, everyday, будни, выходные, каждые N дней/недель/месяцев…), `repost_object` + `repost_comment`, автоудаление из соцсети через N часов (`delete_clock` 0–4382 ч + минуты), `delete_post_date`, `stop_post_date`, `signed` (подпись автора VK), `mute_notifications`, `close_comments`, `wall_pin` + `wall_unpin_date`, `co_owner_ids` (до 4 соавторов VK), `del_task` (удалить из сервиса после публикации), `donut_type` (VK Donut 0–7 дней), `primary_attachments_mode` (сетка/карусель VK), `ads_items` (данные для ЕРИР).
- **Отложенные истории:** VK (отдельное подключение группы), OK, IG*; время показа, ссылка + текст ссылки, повторы, автоудаление.
- **Пакетная загрузка:** картинок (N картинок → N постов), видео, VK Клипов (вертикаль 3–60 с), историй.
- **Наборы страниц:** папки до 20 сообществ для публикации в один клик.
- **Аналитика постов/историй:** по месяцам года — обычные/рекламные посты и репосты; успешные публикации и ошибки по сетям; заработок с маркированной рекламы.
- **Защита от потери черновика:** окно редактора не закрывается случайно (блог #284), предпросмотр видео, редактирование заголовка сниппета VK.
- **API v3** (Bearer JWT, ключ в /dev): `users.getMe`, `groups.getMy`, `uploads.uploadFile`, `posts.getList/getById/create/edit/delete/pause/resume`, `stories.*` (то же), `dictionary.getKktu`, `dictionary.getCountries`.

### 2.3. Маркировка рекламы (38-ФЗ)
- Автоматическая передача креативов в ОРД (VK ОРД — с мая 2026 платный; ОРД Яндекса — бесплатный), получение **erid**, вставка пометки «Реклама», отчётность (акты, статистика), автоудаление.
- Поля: ФИО/наименование, ИНН, КПП (юрлица), ККТУ (классификатор товаров/услуг), страна (ОКСМ), договор, сумма, самореклама (упрощённо).
- Информационные статьи по 3% сбору через ЕРИР, регистрации в РКН (>10 000 подписчиков).

### 2.5. Кросспостинг
Источник: VK, Telegram, Max → приёмники: VK, OK, Telegram, Instagram*, Facebook*, X, Viber (только каналы), Rutube, Max. Фильтры (по ключевым словам, типам вложений), темы частных групп пока не поддерживаются.

### 2.6. AI
AI-ассистент (чат на базе внешних LLM, оплата за каждый ответ по модели, история списаний), AI-бот в сообщениях группы (поддержка VK Donut).

### 2.7. Маркетплейс и рост
- **AdsMarket:** каталог групп для рекламодателей (тематика, описание, старая/новая цена поста, время в топе, охват/сутки, ссылка заказа), фильтры, сортировки, SEO-индексация, персональная ссылка-визитка.
- **Партнёрская программа:** 20% от платежей рефералов на баланс (без вывода денег).
- Промокоды (NEWUSERVPOSTER — 7 дней), скидки партнёров, спецпредложения (Startpack), интеграция Яндекс.Бизнес.
- SEO-машина: блог (355 статей), тысячи публичных страниц групп, AdsMarket-карточки.

## 3. Тарифы и монетизация
- **Модель:** предоплаченный **баланс с посуточным списанием** («платный доступ» вкл/выкл; выключен — заморозка, всё стоп). Автоплатёж при балансе < 100 ₽. Методы: СБП, карты (ЮKassa), ЮMoney, SberPay, T-Pay, Т-Касса, Unitpay. Счета и ЭДО для юрлиц.
- **Бесплатный тариф** — символический (анонимные сообщения/комментарии, расширение). **Пробный период 7 дней** (промокод).
- **Платный — один тариф со всеми функциями, цена зависит только от числа сообществ:**

## 4. Основные пользовательские сценарии
1. **Онбординг:** лендинг → «Войти через VK ID» → выдача прав → кабинет → «Включить платный доступ» (промокод 7 дней) → выбор сообщества (нужно быть админом **и** участником) → «Получить ключ сообщества» → «Установить сервер» (Callback API).
2. **Отложенный пост:** Отложенные посты → Создать пост → текст/вложения → выбор групп или набора → дата/повтор → настройки (закреп, автоудаление, маркировка) → сохранить → список «Запланированные» (пауза/включить/редактировать) → публикация → аналитика ошибок.
3. **Реклама с маркировкой:** Настройки ОРД (VK/Яндекс) → пост с флагом «Реклама» и данными рекламодателя → получение erid → публикация → автоудаление → акты/статистика.
4. **Подключение Telegram/Max:** добавить бота админом в канал → привязать в «Аккаунты».
5. **Модуль VK-автоматизации (антиспам/боты/автопостинг/RSS/граббер):** выбрать раздел → выбрать группу → настроить → «Добавить сообщество» → в «Активные сообщества» → ключ + сервер Callback API.
6. **Биллинг:** пополнение → автоплатёж → ежедневное списание → уведомления при низком балансе → заморозка.

## 6. Слабые места и пробелы Впостера
1. **Нет командной работы:** один владелец на сообщество («кто подключил — тот платит»), нет ролей, приглашений, согласования, комментариев к черновикам, клиентских ссылок. Агентствам неудобно.
2. **VK-центричность:** большинство инструментов (антиспам, боты, конкурсы, воронки, аналитика, граббер) — только для VK. Telegram/Max/OK — только постинг/кросспостинг.
3. **Надёжность и прозрачность:** в отзывах — блокировки, «сгоревшие» отложенные посты, слетающие настройки при обновлениях, постоянные техработы; один хостинг-провайдер; нет публичной страницы статуса/SLA.
4. **Поддержка:** только будни 9–19, нет SLA; конфликтные отзывы о поддержке и блокировке кабинетов.
5. **UX планирования:** нет полноценного визуального **контент-календаря** с drag&drop, рубрик, слотов контент-плана, вариантов поста под каждую сеть и точного предпросмотра; «при большом количестве материалов легко запутаться»; мало функций для историй.
6. **Аналитика:** в основном VK; нет кросс-сетевых дашбордов, отчётов для клиентов (PDF/брендинг), сравнения конкурентов по всем сетям, рекомендаций лучшего времени по всем сетям.
7. **Инбокс только VK:** нет единого инбокса комментариев/сообщений для TG/OK/Max.
8. **AI поверхностный:** чат-ассистент «общего назначения» с поштучной оплатой; нет генерации контент-плана, адаптации текста под сеть, генерации изображений в редакторе, AI-модерации.
9. **Онбординг завязан на VK ID** (нет входа по email/Яндекс ID/Telegram изначально) — риск при проблемах VK-аккаунта.
10. **Нет нативных мобильных приложений** (только PWA), нет медиа-библиотеки/DAM, нет вебхуков/интеграций с Make/n8n/Zapier, API ограничен постами/историями.
11. **Монетизация:** единственный тариф по числу сообществ — нет сегментации (фрилансер/агентство/бизнес), нет годовой скидки, white-label.
12. **Документы:** жалобы на ошибки в актах ОРД и расхождение сумм.

## 8. Что должен добавить наш продукт, чтобы превзойти Впостер

### 8.1. Паритет (обязательно, чтобы переманить пользователей)
Все функции раздела 2: постинг в VK/OK/TG/Max/Rutube (+IG*/FB* с юр. оговорками), истории, повторы, автоудаление, закреп/открепление, пакетная загрузка, наборы страниц, маркировка через несколько ОРД, автопостинг предложки, антиспам, граббер, RSS, кросспостинг, боты, обложки, конкурсы, воронки, мессенджер, AdsMarket, анонимные сообщения, партнёрка, промокоды, PWA, расширение, API.

### 8.2. Превосходство (дифференциаторы)
1. **Рабочие пространства и команда:** workspace → проекты/клиенты → каналы; роли (Владелец, Админ, Редактор, Автор, Аналитик, Клиент-наблюдатель); приглашения по email; многоступенчатое согласование (черновик → на согласовании → одобрено → запланировано); комментарии и @упоминания в посте; публичная ссылка на согласование для клиента; аудит-лог.
2. **Визуальный контент-календарь:** месяц/неделя/день/лента, drag&drop переноса, рубрики с цветами, слоты контент-плана («каждый вт 10:00 — рубрика Кейсы»), очереди с автозаполнением ближайшего слота, массовые операции, фильтры по сетям/проектам/статусам.
3. **Единый редактор с вариантами под каждую сеть** и точным предпросмотром (VK, TG, OK, Max, Rutube), валидация лимитов (длина, число медиа, форматы) до публикации, первый комментарий, кнопки, опросы, UTM-конструктор, сокращатель ссылок с кликами, водяные знаки, шаблоны и подписи.
4. **Медиатека (DAM):** хранение, теги, поиск, обрезка/ресайз под форматы, встроенный графический редактор (шаблоны обложек/историй/каруселей), автотранскодирование видео.
5. **Гарантированная надёжность публикаций:** SLA «опубликовано в течение 60 с от времени» (p99), повторные попытки, мгновенные алерты о сбое (Telegram/email/push), авто-реконнект токенов с предупреждением за N дней, «страховка» — при недоступности сети пост не теряется, переносится и пользователь уведомляется; публичная status-страница; поддержка 24/7 (бот + дежурство).
6. **Кросс-сетевая аналитика и отчёты:** единый дашборд по всем сетям (охват, ER/ERR, подписчики, лучшие посты), сравнение с конкурентами, рекомендации лучшего времени (ML), автоотчёты PDF/XLSX с брендингом агентства по расписанию на email клиенту.
7. **Единый инбокс** комментариев и сообщений VK/TG/OK/Max с назначением ответственного, тегами, шаблонами ответов, AI-подсказками ответа и AI-модерацией (тональность/спам) — антиспам и боты не только для VK, но и для Telegram/Max.
8. **AI-студия:** генерация контент-плана на месяц по нише, генерация и адаптация текста под сеть/тон бренда (brand voice), хэштеги, генерация изображений, рерайт постов из граббера/RSS (уникализация), суммаризация статей для RSS; прозрачная AI-квота в тарифе.
9. **Интеграции:** открытое REST API (всё, а не только посты) + вебхуки + коннекторы Make/n8n/Zapier/Albato, импорт из Google Sheets/CSV, RSS/YouTube/Rutube-импорт, Яндекс.Метрика/UTM.
10. **Входы и безопасность:** VK ID, Яндекс ID, Telegram Login, email+пароль, 2FA, SSO для агентств; шифрование токенов (KMS), хранение ПДн в РФ (152-ФЗ).
11. **Мобильные приложения** iOS/Android (React Native) с push, быстрым согласованием и публикацией.
12. **Гибкие тарифы:** Free (1 проект, 3 канала, 30 постов/мес), Старт, Про, Агентство (мест в команде, white-label, клиентские отчёты), годовая скидка −20%; совместимый режим «посуточного баланса» для переходящих с Впостера; импорт данных из Впостера через их API v3 (по ключу пользователя) — «переезд в один клик».
13. **White-label и клиентский портал** для агентств: свой домен/логотип, клиент видит только свои проекты.
14. **Маркировка 2.0:** несколько ОРД (VK, Яндекс, + другие по мере необходимости), справочник контрагентов и договоров, автоматическое формирование актов, сверка сумм, напоминания о сдаче отчётности, расчёт 3% сбора.
