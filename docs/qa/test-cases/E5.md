## TC-PUB-01 — Публикация в срок: 1000 постов / минута → p99 ≤ 60 с

| Поле | Значение |
|---|---|
| Story / AC | US-5.1 / AC1–AC2 |
| Приоритет | P0 |
| Тип | нагрузка |
| Уровень | load (integration + k6) |
| **Автоматизация** | **авто** (`PipelineLoadIT`, `@Tag("nightly")`; 10k на прототипе) |
| Окружение | CI nightly / staging |

### Ожидание
Все публикации `successful`; p95 ≤ 20 с, **p99 ≤ 60 с**; сверка эмулятор ↔ БД: **0 потерь, 0 дублей**. Полный L2 (120k / 2000/с) — QA-7.
