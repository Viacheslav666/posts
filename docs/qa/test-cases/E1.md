## TC-AUTH-01 - Регистрация email → подтверждение → вход

| Поле | Значение |
|---|---|
| Story / AC | US-1.1 / AC3, AC6 |
| Приоритет | P0 |
| Тип | функциональный |
| Уровень | e2e + integration |
| **Автоматизация** | **авто** |
| Окружение | local / CI / staging |
| Данные | новый email; Mailpit |

### Шаги
1. POST/UI регистрация с паролем ≥ 10, не из словаря утечек.
2. Проверить письмо подтверждения (TTL 24 ч) и создание личного workspace.
3. Перейти по ссылке → email confirmed.
4. Войти теми же credentials.

### Ожидание
Аккаунт активен; можно подключать каналы; workspace Owner создан (US-2.1).
