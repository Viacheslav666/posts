## 3. Персоны
1. **SMM-фрилансер** - 5–30 каналов разных клиентов, важна цена, календарь, быстрое планирование, отчёты клиентам.
2. **SMM-агентство** - 50–1000 каналов, команда 3–30 человек, согласование с клиентами, white-label, роли.
3. **Владелец бизнеса / маркетолог** - 2–10 каналов, AI-помощь в контенте, простота.
4. **Админ VK-пабликов (паблик-мейкер)** - 10–500 сообществ, автоматизации VK (предложка, антиспам, граббер, реклама с маркировкой) - основная аудитория Впостера, цель «переезда».

## 5. Эпики и ключевые user stories MVP (P0, если не указано)
Формат AC: Given/When/Then. Ниже - обязательный минимум; детализировать каждую в отдельном файле.

### E1. Аккаунт и вход
- **US-1.1** Как новый пользователь, я хочу зарегистрироваться по email и паролю, чтобы не зависеть от соцсети.
  AC: (1) пароль ≥ 10 символов, проверка по списку утечек (k-anonymity HIBP-подобная или локальный словарь); (2) письмо подтверждения, ссылка живёт 24 ч; (3) до подтверждения нельзя подключать каналы; (4) повторная регистрация того же email → сообщение «аккаунт существует» без раскрытия деталей в API (защита от энумерации - ответ одинаковый).
- **US-1.2** Вход через VK ID / Яндекс ID (OAuth 2.1 + PKCE). AC: связывание с существующим аккаунтом по подтверждённому email только после подтверждения пользователем.
- **US-1.3** 2FA TOTP + 10 резервных кодов. AC: при включённой 2FA вход без кода невозможен; сброс 2FA только через поддержку с верификацией.
- **US-1.4** Восстановление пароля. AC: ссылка 1 ч, одноразовая; все сессии завершаются после смены.
- **US-1.5** История входов (дата, IP, устройство) и завершение сессий.
- **US-1.6** Часовой пояс пользователя (по умолчанию из браузера); все даты в UI в TZ пользователя, хранятся в UTC.

### E2. Workspace, проекты, команда
- **US-2.1** При регистрации создаётся личный workspace; можно создать дополнительные.
- **US-2.2** Проекты внутри workspace (клиенты/бренды), каналы привязываются к проекту.
- **US-2.3** Приглашение участника по email с ролью и набором проектов. AC: приглашение живёт 7 дней; лимит мест по тарифу; при превышении - предложение апгрейда.
- **US-2.4** Аудит-лог действий (кто, что, когда, IP) - хранится 1 год, экспорт CSV (P1).

### E3. Каналы (подключение соцсетей)
- **US-3.1 VK:** подключить личную страницу и группы, где пользователь админ/редактор. AC: список доступных групп с аватарами; при отсутствии прав - понятная ошибка с инструкцией; токен группы получаем для групп с Callback-функциями (Фаза 2).
- **US-3.2 Telegram:** подключение канала/группы через нашего бота: пользователь добавляет @PostsBot админом с правом публикации → вводит @username или пересылает пост → канал появляется. AC: проверка прав бота (`can_post_messages`, `can_edit_messages`, `can_delete_messages`, `can_pin_messages`).
- **US-3.3 OK:** OAuth, выбор групп. **US-3.4 Max:** подключение через бота Max аналогично TG.
- **US-3.5** Статус канала: Активен / Требует переподключения / Нет прав / Отключён. AC: при истечении/отзыве токена - уведомление владельцу и Admin’ам в течение 5 мин; запланированные посты канала не удаляются, а получают статус «ожидает канал».
- **US-3.6** Наборы каналов (до 50 в наборе, у Впостера 20) для публикации в один клик.
- **US-3.7** Лимит каналов по тарифу.

### E4. Создание и планирование постов
- **US-4.1** Редактор: общий текст + **вариант под каждую сеть** (можно переопределить текст/медиа/настройки). AC: предпросмотр каждой сети; счётчик символов с лимитом сети; блокировка сохранения при нарушении лимитов с подсветкой причины.
- **US-4.2** Медиа: до 10 фото (VK) / 10 (TG альбом) / видео до лимита тарифа; форматы JPG/PNG/WEBP/GIF/MP4/MOV; документы. AC: прогресс загрузки; резюмируемая загрузка для файлов > 50 МБ; автоконвертация неподдерживаемых форматов.
- **US-4.3** Форматирование: Telegram (жирный, курсив, подчёркнутый, зачёркнутый, спойлер, код, цитата, ссылка), Max (поддерживаемое подмножество); для VK/OK - plain text с предупреждением.
- **US-4.4** Настройки поста: дата/время (или «сейчас»), повтор (ежедневно, будни, выходные, каждые N дней/недель/месяцев, до даты), закрепить (+ дата открепления), автоудаление через N часов/в дату, отключить уведомление, закрыть комментарии (VK/OK), подпись автора (VK), первый комментарий, кнопки-ссылки (TG/Max), карусель/сетка (VK).
- **US-4.5** Черновики и автосохранение каждые 5 с; защита от закрытия вкладки с несохранёнными изменениями.
- **US-4.6** Контент-календарь: месяц/неделя/список; перетаскивание поста меняет время (с подтверждением для опубликованных - запрещено); фильтры по проекту/каналу/сети/статусу/автору; цветовая маркировка статусов.
- **US-4.7** Массовые операции: пауза/возобновление/удаление/перенос выбранных постов.
- **US-4.8** Статусы поста: Черновик → (На согласовании → Одобрен/Отклонён - Фаза 2) → Запланирован → Публикуется → Опубликован / Частично опубликован / Ошибка / Приостановлен / Удалён из сети. Статус по каждому каналу отдельно, со ссылкой на опубликованный пост.
- **US-4.9** Репост (VK/TG/OK) с комментарием.

### E5. Надёжность публикации и уведомления
- **US-5.1** Пост публикуется в пределах 60 с от времени (p99). AC проверяется нагрузочным тестом.
- **US-5.2** При временной ошибке сети (5xx, flood control, 429) - автоповторы с экспоненциальной задержкой до 30 мин суммарно; при постоянной ошибке (нет прав, токен) - статус «Ошибка» с человекочитаемой причиной и кнопкой «Повторить».
- **US-5.3** Дубликатов публикаций не бывает (идемпотентность) - AC: при повторной доставке задачи из очереди пост в сети создаётся максимум 1 раз (проверка хаос-тестом).
- **US-5.4** Уведомления (email, Telegram-бот, в приложении, push PWA) о: ошибке публикации, отключении канала, низком балансе/окончании тарифа, приглашении, запросе согласования. Настройки уведомлений по типам.

### E6. Биллинг
- **US-6.1** Тарифы (стартовое предложение, утвердить с владельцем):
  | Тариф | ₽/мес (год −20 %) | Каналы | Места в команде | Посты | AI-кредиты |
  |---|---|---|---|---|---|
  | Free | 0 | 3 | 1 | 30/мес | 20 |
  | Старт | 390 | 10 | 1 | ∞ | 200 |
  | Про | 990 | 30 | 3 | ∞ | 1 000 |
  | Агентство | 2 990 | 100 (+250 ₽ за каждые +25) | 10 (+ доп. места) | ∞ | 5 000 |
  | Enterprise | договор | | | | |
  Плюс опция «баланс с посуточным списанием» для мигрантов с Впостера (P1).
- **US-6.2** Пробный период 7 дней тарифа Про без карты.
- **US-6.3** Оплата ЮKassa (карта, СБП, SberPay, ЮMoney, T-Pay), автопродление, чек 54-ФЗ на email.
- **US-6.4** Счёт для юрлица (PDF), закрывающие документы, ЭДО (P1).
- **US-6.5** При неоплате: grace 3 дня (публикации работают, баннер), затем «заморозка»: публикации ставятся на паузу (не удаляются!), данные хранятся 90 дней.
- **US-6.6** Промокоды (скидка %, фикс. сумма, дни триала), лимит активаций, срок.

### E7. Админ-панель (внутренняя)

## 8. Матрица возможностей сетей - что проверить и зафиксировать
Для каждой сети: типы постов, лимиты текста, количество/размер/формат медиа, форматирование, отложенная публикация нативно (VK `publish_date`), редактирование/удаление после публикации, закреп, первый комментарий, истории, лимиты API (запросов/с, публикаций/сутки), срок жизни токенов, требования к правам, вебхуки. Источник - официальная документация (dev.vk.com, core.telegram.org/bots/api, apiok.ru, dev.max.ru, документация Rutube). Каждое значение - со ссылкой и датой проверки. Числовые лимиты передаются Бэку для конфигурации `posts.ratelimit.<network>.*` и `NetworkCapabilities` (Java), фронт получает их через `GET /api/v1/networks/capabilities`.

## 9. Метрики успеха MVP
Активация (подключил канал + запланировал пост за 1-й день) ≥ 40 %; доля успешных публикаций ≥ 99.5 % (ошибки по вине сервиса ≤ 0.1 %); конверсия триал → оплата ≥ 15 %; retention M1 ≥ 50 %; NPS ≥ 40; время ответа поддержки < 15 мин (24/7 бот + дежурство).

## 10. Definition of Ready для story
Есть описание ценности, AC в Given/When/Then, макет/ссылка на экран (если UI), зависимости, приоритет, оценка от Бэка/Фронта, тестовые данные от Тестировщика.
